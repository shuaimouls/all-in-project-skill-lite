# Goal 监工（lite）

> 本 skill 是目标级协调器，不是超级 Agent。它只在用户明确启动并完成一次授权确认后运行；任何时刻仍只有一个生命周期 skill 为 `ACTIVE`。

## 适用场景

- `项目备忘录.md`、`docs/需求与架构.md`、`docs/开发进度.md` 和可执行 `vault/` 已就位。
- 用户明确要求“监工目标”“自动推进到完成”或“持续完成当前版本”。
- 规划文档已写明目标、非目标、当前目标版本和完成定义。

规划不完整、目标冲突或 vault 无法执行时，先转《项目初始化》《遗留项目接入》《需求修改》或《最小上线标准评估》。

## 启动合同

启动时只询问一次，逐项记录动作、精确对象、范围和是否允许自动执行：

| 动作 | 授权范围 |
|---|---|
| 文档/代码/测试写入 | 指定项目目录、文件或当前任务 |
| 安装依赖/联网下载 | 指定包、来源和用途 |
| 测试/构建/开发服务 | 指定命令或项目脚本 |
| 本地 commit | 指定分支和当前 Goal 任务 |
| 建立/切换分支 | 指定分支名和用途 |
| 本地 merge | 指定源、目标和策略 |
| push | 指定 remote 和 branch |
| 部署 | 仅限项目已有且已记录的部署命令/环境 |
| 删除临时文件/预览 | 指定目录和条件 |
| 删除文件/分支/数据迁移 | 必须逐项、逐对象说明 |

未勾选动作不可执行。`force push`、`reset --hard`、rebase 或其他历史改写不纳入通用 Goal 授权；生产部署不因本 skill 自动获得能力。授权不可扩展到新目标、新版本、新分支或未列出的文件。

一次性授权不替代产品或技术决策。新技术栈/依赖、公共 API、数据迁移语义、权限安全、合规、许可证冲突和需求矛盾仍需用户决定。

## 状态机

```text
PREFLIGHT
  → GOAL_CONFIRMED
  → SELECT_NEXT
  → DELEGATE
  → VERIFY
  → SELECT_NEXT
  → COMPLETED

任一阶段可转 BLOCKED；语义冲突转 WAITING_USER。
```

## 自动推进循环

1. 读取目标版本、完成定义、禁止项、授权合同和当前进度。
2. 计算 ready 任务：依赖已完成、范围明确、授权覆盖、无未决语义冲突。
3. 选择顺序：当前版本上线阻断任务 → 当前版本普通任务 → 后续版本中不阻塞当前目标的独立任务。
4. 将唯一 `ACTIVE` 交给对应 skill：实现交《项目开发》，行为缺陷交《Bug修复》，需求变化交《需求修改》，前端决策交前端 skill，审查/合并遵循独立门禁。
5. 接收交接：状态、改动、测试/验收证据、未完成项、下一动作。
6. 验证目标完成条件后重新计算 ready 集合，继续或结束。

Goal 在委派期间是 `COORDINATING/ASSISTING`，不能用自身身份扩大执行 skill 的权限。

## 阻断处理

“优先绕过”只允许：更换等价工具、使用本地资产替代不可达网络、降低并行量、替换中断 Agent、重排无依赖任务、提前做后续版本独立基础任务。不得降低验收标准，不得改测试迁就实现，不得跳过安全、权限、数据完整性、必要测试、用户决策或审查门禁。

当前任务阻断时：

- 先尝试一次已授权、需求等价、可验证、非破坏性的替代路线。
- 没有替代路线时保留阻断原因，继续寻找任何版本的 ready 任务。
- 跨版本执行时保持原任务版本归属；后续任务不能计入当前版本完成。
- 同一问题修复两次仍失败，按《项目开发》规则升级，不再循环。

完全阻断是指：没有同时满足依赖、授权、需求等价和可验证条件的 ready 任务，且 Goal 完成条件未满足。

## 完成标准

只有同时满足以下条件才标记 `COMPLETED`：

- 当前 Goal 所需版本的必需任务均完成；
- 版本范围内的验收标准、测试和必要审查均有当前证据；
- 没有阻断 finding 或未决产品/技术冲突；
- docs、vault、进度和接口的局部同步检查通过；
- merge、push、部署是否属于完成条件，按启动合同逐项判断。

## 完全阻断升级包

```markdown
## Goal 阻断升级
- Goal / 目标版本：
- 当前任务：
- 已完成：
- 未完成：
- 证据：
- 已尝试路线：

- 影响：
- 方案 A/B/C：

- 需要用户决定：
```

## 反模式

- 把一次授权解释成未列出的全仓、全版本或全外部系统授权。
- 为了“自动完成”跳过安全、测试、审查、需求确认或数据迁移门禁。
- 把后续版本任务算作当前版本已完成。
- 自己替代《项目开发》《Bug修复》《代码审查》作专业判断。
- 遇到局部阻断就停下，或无限重复同一失败路线。
